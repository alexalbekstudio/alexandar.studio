# 🚀 ServisMasterOS — Uputstvo za instalaciju / Installation Guide

## [SRPSKI]

### Desktop verzija (Windows)
1. Raspakujte preuzeti `.zip` fajl u željeni folder (npr. `C:\ServisMasterOS`).
2. Dvaput kliknite na `ServisMasterOS.exe`.
3. Baza podataka (`servismaster.db`) kreiraće se automatski u istom folderu.
4. Aplikacija će se otvoriti u vašem podrazumevanom pretraživaču.
5. Unesite licencni kod u sekciji "Podešavanja" da biste otključali paket.

### Server verzija (Docker)
1. Uverite se da imate instaliran Docker i Docker Compose.
2. U folderu aplikacije pokrenite:
   `docker compose up -d`
3. Aplikacija je dostupna na: `http://localhost:8000`
4. Unesite licencni kod u sekciji "Podešavanja" da biste otključali paket.

## [ENGLISH]

### Desktop Version (Windows)
1. Extract the downloaded `.zip` file to a folder of your choice (e.g., `C:\ServisMasterOS`).
2. Double-click `ServisMasterOS.exe`.
3. The database (`servismaster.db`) will be created automatically in the same folder.
4. The application will open in your default browser.
5. Enter your license key in the "Settings" section to unlock your package.

### Server Version (Docker)
1. Ensure Docker and Docker Compose are installed.
2. In the application folder, run:
   `docker compose up -d`
3. The app is available at: `http://localhost:8000`
4. Enter your license key in the "Settings" section to unlock your package.
